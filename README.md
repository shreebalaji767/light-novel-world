# Light Novel World

A procedurally generated long-form light novel website built with Python, Flask, HTML, CSS, and JavaScript.

Project Identifier: `blssnvj21`

---

## 1. What Is This Website?

Light Novel World is a web application that automatically creates a new fictional light novel when the website is opened or refreshed.

Each generated novel contains:

- A unique novel title
- A genre
- A secondary genre
- A fictional world
- A protagonist
- A power/ability system
- A major conflict
- A faction
- Supporting characters
- Multiple story arcs
- 600 chapters
- Approximately 800 words per chapter
- A responsive reading interface

The website does not require the visitor to create an account.

There is no login system.

There is no database.

There is no localStorage.

There is no sessionStorage.

---

# 2. Basic Website Flow

The website works approximately like this:

```text
Visitor opens website
        │
        ▼
Flask receives request
        │
        ▼
A fresh random novel seed is created
        │
        ▼
Novel generator creates the novel
        │
        ├── Title
        ├── Genre
        ├── World
        ├── Characters
        ├── Power system
        ├── Conflict
        └── Story arcs
        │
        ▼
Flask sends the generated novel to the HTML template
        │
        ▼
Browser displays the novel website
        │
        ▼
Visitor selects a chapter
        │
        ▼
JavaScript requests the chapter from Flask
        │
        ▼
Flask generates that chapter from:
        │
        ├── Novel seed
        └── Chapter number
        │
        ▼
Chapter is returned as JSON
        │
        ▼
JavaScript displays the chapter

# STATIC PARODY BUILD

The production website is now a **static site generated by Python**.

Python runs at build time:

```text
Python generator
     ↓
4 parody novels
     ↓
600 chapters per novel
     ↓
800 words per chapter
     ↓
site/
     ├── index.html
     ├── catalog.json
     ├── novel-001/
     │   ├── index.html
     │   └── chapters/001.json ... 600.json
     ├── novel-002/
     └── ...
```

The browser does **not** call Flask to generate chapters.

This removes runtime chapter-generation failures such as:

```text
used.has is not a function
Generation stopped safely
```

because chapter generation happens once during the Python build and the finished JSON files are served as static assets.

## Build locally

```bash
pip install -r requirements.txt
python build.py
```

The generated website is in `site/`.

To build a different number of parody novels:

```bash
NOVEL_COUNT=6 python build.py
```

The default build creates 4 parody novels.

## Render

Render builds with:

```bash
pip install -r requirements.txt && python build.py
```

and publishes:

```text
site/
```

No Flask/Gunicorn process is required for the production static site.
